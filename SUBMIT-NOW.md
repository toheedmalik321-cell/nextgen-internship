## Step 1: Google Drive (10 minutes)

1. Open https://drive.google.com and sign in.
2. Click **New → Folder**, name it `Toheed Mehmood NextGen Internship`.
3. Open that folder. Drag these seven files into it:
   - the six `Task-*.zip` files
   - `Full-Internship-Report.pdf`
4. Wait until every upload finishes. Large ones are only 20 to 90 KB, so this is fast.
5. Right-click each ZIP, choose **Share**, set **General access** to **Anyone with the link**, role **Viewer**, then **Copy link**.
6. Paste each link into `SUBMISSION-TRACKER.md` next to its task.
7. Share the parent folder the same way and keep that link too. It is a useful backup.

Check one link in an Incognito window. It must open without asking for a Google sign-in.

**Form will not accept the PDF.** Confirm the file is `Full-Internship-Report.pdf`, 95,649 bytes, and not open in a PDF viewer.
