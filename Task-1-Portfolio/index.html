01 / About

Layout is a language

I am a web development intern at Next Gen Software Hub, working remotely from Lahore, at the end of an eight-week programme. My work is deliberately unglamorous: semantic markup, layout systems that hold up at every width, and JavaScript that makes a page better without taking it over.

I build mobile-first. The 360 px layout is the design, not a fallback — the wide layout is a consequence of it. Flexbox handles one-dimensional flow, CSS Grid handles two, and I try not to reach for either when a third option would be simpler.

What I care about most is that the page still works for someone on a slow connection, a mid-range Android phone, or a keyboard instead of a mouse. Everything here is hand-written: no framework, no build step, no placeholder copy.

04 / Timeline

Eight weeks, five projects

One marker per week of the internship. Each marker lights up as it enters the viewport.

  1. Week 01

    HTML, CSS and Git foundations

    Document structure, Flexbox and Grid, then Git and GitHub: repositories, commits and branching. The baseline every later build sits on.

  2. Week 02

    Portfolio and Taskbook

    This responsive portfolio, plus the to-do list: add, edit, complete and delete, with filters and a versioned localStorage store.

  3. Week 03

    Animation and advanced JavaScript

    Keyframe animation and transitions on hover, then event delegation, closures and promises applied to a filterable gallery.

    Plates gallery

    Sixteen locally authored SVG studies with category filters, debounced search, three densities and a keyboard-trapped lightbox.

  5. Week 05

    Four-column board with pointer and keyboard drag-and-drop, undo/redo history, insights and offline persistence — documented for code review.
